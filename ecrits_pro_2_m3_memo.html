L'accord du participe passé

Fiche mémo — employé seul, avec être, avec avoir

1 ·Trouver la bonne terminaison

Avant d'accorder, il faut écrire la bonne lettre finale. Un réflexe suffit : mettez le participe au féminin, la lettre muette s'entend.

TerminaisonVerbesTest du féminin
-éverbes en -erun dossier clôturé · une commande bloquée
-i / -isfinir, choisir, mettre, transmettre…un dossier fini → finie · un document transmis → transmise
-tfaire, dire, écrire, ouvrir…un dossier ouvert → ouverte · un retour fait → faite
-urecevoir, prévoir, rendre…un colis reçu → reçue
LA CONFUSION À ÉVITER-é ou -er ? Remplacez par pris / prendre (vu en écrits pro 1) : « la commande a été bloquée » (prise), « merci de bloquer la commande » (prendre).

2 ·Les trois règles qui couvrent l'essentiel

CasLa règleExemples en relation client
Employé seulIl s'accorde comme un adjectif avec le nom qu'il accompagne.les pièces demandées · une commande annulée · les frais facturés
Avec être (y compris « a été », « ont été »)Il s'accorde avec le sujet.Votre commande est bloquée · Les colis ont été livrés · La facture a été envoyée
Avec avoirIl ne s'accorde jamais avec le sujet. Il s'accorde avec le complément d'objet direct (COD) seulement s'il est placé avant le verbe.Nous avons reçu vos justificatifs (COD après) · Les justificatifs que nous avons reçus (COD « que » avant)
LA MÉTHODE AVEC AVOIRPosez la question « quoi ? » ou « qui ? » après le participe. Si la réponse se trouve avant le verbe (souvent « que », « l' », « les »), accordez avec elle. Sinon, n'accordez pas.

3 ·Les cas qui reviennent dans les écrits de relation client

Phrase typeRaisonnement
Les justificatifs que vous nous avez transmisTransmis quoi ? « que » = les justificatifs, avant → masculin pluriel (le s est déjà là).
La remise que nous avons appliquéeAppliqué quoi ? « que » = la remise, avant → appliquée.
Votre demande, je l'ai transmise au serviceTransmis quoi ? « l' » = votre demande, avant → transmise.
Nous vous avons adressé un courrierAdressé quoi ? un courrier, après → pas d'accord. « vous » n'est pas le COD.
Vos coordonnées ont été mises à jour« ont été » = être → accord avec le sujet, féminin pluriel.
Les commandes perdues doivent faire l'objet d'une réclamationEmployé seul → accord avec « les commandes ».

4 ·À retenir

  1. Mettez le participe au féminin pour trouver sa lettre finale.
  2. Seul ou avec être : accord avec le nom ou le sujet.
  3. Avec avoir : jamais d'accord avec le sujet ; accord avec le COD seulement s'il est placé avant.
  4. « a été », « ont été » : c'est l'auxiliaire être — accord avec le sujet.
